# CodeAlpha Language Translation Tool

## Project Overview
A web-based application developed as part of the CodeAlpha Artificial Intelligence Internship. It translates text between different languages using a translation API.

## Features
- Select source and target languages
- Translate text between supported languages
- Copy translated text
- Listen to translated text using text-to-speech
- Validate empty input
- Responsive user interface
- Display translation status and errors

## Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API
- Web Speech API

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enter the text you want to translate.
4. Select the source and target languages.
5. Click **Translate Text**.
6. View the translated result.

An active internet connection is required for translation.
